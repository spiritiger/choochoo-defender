## 三、v2 求解管线（js/state.js `recomputeRailsV2`）

```
乐观探测(tol0,ki0) → [未中] 跳步定档(ki: 0,1,2,4,8.., 三态探测) → 全起点锦标赛
→ 洗环通道(⑥⑦+掉头格手术) → 剥层终落 → 精确裁判 → R4 终选(prev 并列沿用)
→ 口袋补挂(链缝拼接 → 容差阶梯 lasso) → 后处理(⑥trim→straight→⑦reweave→十字对重接)
```

关键设计事实：可行性对补格预算**单调**（跳步不漏解）；**升档付无解证明（指数）、降档只付命中（毫秒）**；脏首命中是原料不是垃圾（洗环）；anytime = 预算内任意时刻手中有合法环。

## 四、大王亲抓的六个 bug（全部修复 + 回归锁）

1. 多余十字（k60 后续盘）→ 后处理漏形态 → 十字对重接
2. 往返格（死角盘脖子格）→ H5b 禁令 + 区域层挂接前移
3. 2 列蛇形（k60）→ 补格两层看不见贴内墙格 → 洞邻格入搜索
4. 死端误伤（09:57/09:59 两盘对比）→ 连接口袋的连接格被当必须覆盖 → 可走不必到
5. 吊灯口袋（10:10 撤销盘）→ 口袋全-or-无 → 容差阶梯 + 命中≠采纳
6. 右侧两格（10:47 盘）→ 小口袋低于搜索下限 → 链缝拼接

另：转正轮 test_rules 抓到省略闸跳过未保证站台完整的真游戏 bug（newGame 同指纹误跳 ⇒ 站台 null）。
