# 地图矩阵模板（11 列 × 15 行）

配图：`docs/地图坐标参照图.png`（左边是空坐标网格，照着数格子即可）

> **规则**：`r0` 在最上面，每行 **11 个字符**，一共 **15 行**。
> 发给我时，只要给「**地形矩阵** + 你期望的**轨道矩阵**」两份，我就能直接跑算法逐格对比，告诉你差在哪、为什么。

## 符号

| 符号 | 含义 |
|---|---|
| `#` | 废墟（挡轨，只有清掉才能铺轨） |
| `.` | 空白（当前就可铺轨） |
| `E` | 经济建筑 |
| `C` | 镇中心（整局唯一） |
| `O` | **你期望铁轨占的格**（只在「轨道矩阵」里用） |

**等价写法（坐标列表，更省字）**

- 地形（只列废墟）：`(0,0)(3,0)(5,0)(8,0)(10,0) …` —— 全列出来比较多，还是推荐整行字符串。
- 轨道：`(4,5) (5,5) (6,5) (7,5) (7,6) (7,7) (7,8) (6,8) (5,8) (4,8) (4,7) (4,6)`

## 你可以怎么用

1. **只说地形**（"这个图应该有什么样的轨道"）→ 我跑算法，把结果和你心里的预期比。
2. **地形 + 轨道都给** → 我逐格 diff，直接定位「哪一格没长上去 / 多长了」，再归因到规则或地形。
3. 若轨道里有**斜角相接**（比如 `(7,9)` 和 `(8,8)` 对角贴着），也照实标 —— 我一眼就能看出这是不是故意的。
